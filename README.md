# Driver-Drowsiness-Detection-and-Alert-System
Camera-Based Driver Drowsiness Detection and Alert System Using Edge Machine Learning.

### 1. Project Overview

Driver drowsiness is a significant road safety concern that can reduce driver attention, reaction time, and overall driving performance.

This project focuses on developing a camera-based Driver Drowsiness Detection and Alert System using edge machine learning. The proposed system monitors driver's eye activity through a camera, processes visual data using a lightweight Convolutional Neural Network (CNN), and detects potential signs of drowsiness.

When extended eye closure is detected, the system is designed to activate an alert using an actuator such as a buzzer or vibration motor.

The project aims to develop a system that captures and analyzes eye activity in real time and activates an alert when signs of drowsiness are detected
